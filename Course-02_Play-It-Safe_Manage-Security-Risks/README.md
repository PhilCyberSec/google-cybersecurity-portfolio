# Course 02 – Play It Safe: Manage Security Risks

## Overview

This course focused on risk management, security frameworks, and control assessments. It introduced how organizations identify risk, evaluate controls, and document security gaps in a structured and compliant way.

## Key Topics

- NIST RMF and risk assessment concepts
- Security frameworks such as NIST CSF and ISO 27001
- Control categories: technical, managerial, and operational
- Internal audit and compliance review
- Security documentation and assessment reporting
- The relationship between risk, controls, and business operations
