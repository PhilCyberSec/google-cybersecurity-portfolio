# Course 02 – Play It Safe: Manage Security Risks

## Overview

This course covered security frameworks, controls, and risk management processes. Topics included the NIST RMF, security audits, SIEM tools, and playbooks for incident response.

## Key Topics

- NIST Risk Management Framework (RMF)
- Security frameworks: NIST CSF, ISO 27001, SOC
- Security controls and their categories (technical, operational, managerial)
- Conducting internal security audits
- SIEM tools and their role in security operations
- Incident response playbooks
