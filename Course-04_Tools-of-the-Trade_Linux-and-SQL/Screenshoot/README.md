# Course 4: Tools of the Trade — Linux and SQL

## Overview
This course covers the foundational tools used by cybersecurity analysts daily —
the Linux operating system and SQL for database querying. It focuses on navigating
the Linux file system, managing file permissions, and applying filters to SQL
queries to retrieve security-relevant data.

## Topics Covered
- Linux operating system and command line interface
- File system navigation and management
- File permissions and authorization
- User and group management
- SQL queries and filters
- Applying SQL to security investigations
