# Course 07 – Automate Cybersecurity Tasks with Python

## Overview

This course introduced Python programming in the context of cybersecurity. Topics included Python syntax, working with strings and lists, regular expressions, file I/O, and writing scripts to automate common security tasks.

## Key Topics

- Python fundamentals: variables, data types, functions, loops, conditionals
- String and list operations for parsing security data
- File I/O: reading from and writing to files
- Regular expressions for pattern matching in logs
- Writing reusable functions and modules
- Debugging Python scripts
