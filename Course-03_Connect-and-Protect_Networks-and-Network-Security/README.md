# Course 03 – Connect and Protect: Networks and Network Security

## Overview

This course explored how networks are built, how communication occurs across them, and how security controls help protect those systems from misuse and attack.

## Key Topics

- Network architecture and system components
- TCP/IP and OSI models
- Common protocols and services
- Network threats and attack methods
- Firewalls, VPNs, and segmentation strategies
- IDS/IPS and network hardening concepts
