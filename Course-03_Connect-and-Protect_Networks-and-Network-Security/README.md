# Course 03 – Connect and Protect: Networks and Network Security

## Overview

This course explored how networks function and how to secure them. Topics included the TCP/IP model, OSI model, common network protocols, firewalls, VPNs, and network attack mitigation strategies.

## Key Topics

- Network architecture and components (hubs, switches, routers, firewalls)
- TCP/IP and OSI models
- Common network protocols: HTTP/S, DNS, DHCP, TCP, UDP, ARP
- Network attacks: DoS/DDoS, man-in-the-middle, packet sniffing, replay attacks
- Firewalls, VPNs, proxies, and network hardening
- Intrusion Detection and Prevention Systems (IDS/IPS)
