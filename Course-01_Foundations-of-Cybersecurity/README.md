# Course 01 – Foundations of Cybersecurity

## Overview

This course introduced the core principles of cybersecurity, including the history of the field, fundamental security models, common attack types, and the role of security professionals in protecting digital assets.

## Key Topics

- Cybersecurity history and evolution
- CIA Triad and the security mindset
- NIST Cybersecurity Framework (CSF)
- Threats, attacks, and common attack vectors
- Security domains and governance basics
- The role of a cybersecurity analyst in an organization
