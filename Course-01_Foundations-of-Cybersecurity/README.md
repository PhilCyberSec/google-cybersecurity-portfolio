# Course 01 – Foundations of Cybersecurity

## Overview

This course introduced the foundations of cybersecurity, including the history of cybersecurity, core security frameworks (NIST CSF, CIA Triad), common threats and attacks, and the role of a security analyst.

## Key Topics

- History and evolution of cybersecurity
- The CIA Triad (Confidentiality, Integrity, Availability)
- NIST Cybersecurity Framework (CSF)
- Common attack types: phishing, malware, social engineering
- Security domains: CISSP's 8 security domains
- Security tools: SIEMs, playbooks, network protocol analyzers
